#  Pizza Pete's - Application de Commande de Pizzas

Une application complète de commande de pizzas avec frontend React et backend Node.js/Express.

##  Fonctionnalités

- **Frontend** : Interface utilisateur moderne avec React
- **Backend** : API REST avec Node.js, Express et MongoDB
- **Authentification** : Inscription de l'utilisateur
- **Base de données** : MongoDB avec Mongoose
